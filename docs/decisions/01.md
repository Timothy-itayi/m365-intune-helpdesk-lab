## Docker image: native arm64 PowerShell base

- **Incident:** [Docker build failure on Apple Silicon](../incidents/01-setup.md#incident-docker-build-failure-on-apple-silicon)
- **Decision:** Build the `m365-helpdesk-pwsh` image on a native arm64 PowerShell tag instead of `powershell:latest` with `--platform=linux/amd64`.
- **Reason:** `powershell:latest` has no `linux/arm64` image, and running the amd64 image under emulation on Apple Silicon crashed the .NET runtime (exit code 133).
- **Chosen tag:** `mcr.microsoft.com/powershell:lts-azurelinux-3.0-arm64`
- **Trade-off:** The tag is arm64-only, so it will not build on x86 hosts or CI runners. If that becomes a requirement, parameterise the tag with a build argument.
- **Status:** Proposed. The rebuilt image has not been verified yet.
