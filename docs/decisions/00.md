# Decisions

Related: [osTicket Lab Setup](../../evidence/00-setup/00.md) (setup and screenshots), [incident report](../incidents/00-setup.md)

- Reused the existing Operations Lab instead of creating a separate osTicket project.
- Used Docker Compose to run osTicket and MariaDB as separate services.
- Used the `mariadb` Docker service name as the database host.
- Used the same `OST_DB_PASSWORD` environment variable for MariaDB and osTicket.
- Used persistent Docker volumes for the database and attachments.
- Confirmed the MariaDB issue was authentication-related by checking container logs.
- Recreated the MariaDB volume because the existing database only contained disposable lab data.
- Decided not to rely on an unrecorded random MariaDB root password for future reusable lab setups.
